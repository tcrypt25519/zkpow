## Notes

With almost no internal edges resolved (see [Dependencies](dependencies.md)), the order above is close to path order, not a real initialization order. Rust modules have no import-time side effects; the one listed is a Python regex compile. The factory rows are name matches only: `create_checksum` computes the 4-byte SHA-256d checksum of a P2P message, and the `test_utils` rows build test stores.
